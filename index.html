使い方マニュアル

姿勢分析システム 操作マニュアル

はじめて使う方へ。下の手順に沿って進めれば、撮影から結果の共有まで操作できます。

1

ログイン・契約状態の確認

🔐 ログイン → 契約状態を確認

Googleアカウントでログインし、画面に表示される契約状態を確認します。

2

顧客を登録・選択

👥 顧客一覧 → ＋ 新規登録 → 登録

カタカナ・性別・生年月日を入力して登録します。登録済みの方は顧客一覧から選択します。

3

3方向の写真を撮影

🧍① 正面🧍② 右側面🧍③ 左側面

頭から足先まで全身を写します。距離は約2〜3m、スマホの高さは胸〜みぞおち付近を目安に、毎回同じ条件で撮影してください。

4

ランドマークを確認・微調整

🟠 AI検出 → ✋ ランドマークを微調整

オレンジ色の点が身体の対応部位からずれている場合は、点をドラッグして調整します。調整後の位置は分析に反映されます。

5

3D分析と結果を確認

📊 3D分析を作成 → スコア・姿勢タイプ・筋肉の推定

総合・正面・側面・回旋のスコア、姿勢の傾向、3Dモデルを確認します。数値は比較のための参考指標です。

6

LINEで結果を共有

📋 分析レポート → 🟢 LINEで共有

患者さんに見せるレポートを確認し、LINEで共有します。写真はFirebaseに保存しない運用です。

7

履歴を確認・比較

🗂️ 分析履歴 → 2回分を選択 → 比較

保存された数値・所見を確認し、過去と今回の変化を比較できます。過去の写真は保存されません。

📍 ランドマークの基準位置を見る

写真上の推定点を、身体の目安となる部位と照らし合わせます。AIが骨の位置を直接測定するわけではありません。

📐 姿勢スコアの計算根拠・注意事項

点数の計算根拠（独自比較スコア）

以下は診断基準や公的な標準スコアではなく、施術前後の比較のために設定されたアプリ独自の指標です。

正面スコア

100 − 正面減点 を0〜100に収めて四捨五入します。

正面減点 = 14 + max(0, |肩傾斜角|−0.20)×7 + max(0, |骨盤傾斜角|−0.35)×9 + max(0, |頭部偏位%|−0.15)×3.4 + 正中線減点

正中線減点は、頭部と骨盤中心がともに許容範囲内なら0点、両者が同じ側で範囲外なら10点、それ以外の範囲外の場合は20点です。許容幅は頭から足首までの画像上の縦距離の1%（最低0.003）です。

側面スコア

各側面で 頭部と肩中央の水平距離×100×1.7 + 肩中央と股関節中央の水平距離×100×1.25 を計算し、左右の平均を D とします。

側面スコア = round(clamp(100 − [19 + max(0, D−0.35)×3.25], 0, 100))

回旋スコア

左右側面の非対称性をもとに、上半身・下半身を別々に評価します。左右側面の差は身体の画像上の縦距離で正規化した参考指標で、解剖学的な回旋角度を直接測定したものではありません。

非対称性の値評価点数
1%未満ほぼなし90
1%以上1.5%未満ごく軽度80
1.5%以上2.5%未満軽度70
2.5%以上4.5%未満中等度60
4.5%以上強い40

境界値は低い点数側に入ります。上半身の評価には耳・肩・肩と骨盤の相対位置の左右差の最大値、下半身には股関節の左右差を使用します。回旋スコアは上半身と下半身の点数の平均（四捨五入）です。判定に必要な点がない場合は判定不可です。

総合スコア

回旋を判定できる場合：正面×0.45 + 側面×0.40 + 回旋×0.15 を四捨五入。

回旋を判定できない場合：(正面×0.45 + 側面×0.40)÷0.85 を四捨五入。

4. 精度と注意事項

- 写真の角度、距離、服装、姿勢、AI検出誤差、ランドマーク補正で結果は変動します。比較時は撮影条件をそろえてください。

- スコアはアプリ独自の比較用参考値です。臨床的な妥当性、再現性、正常値の根拠となる研究を確認したものではありません。

- 緊張・機能低下の筋肉表示は写真からの推定候補であり、筋力や筋緊張を直接測定していません。

- 回旋の3D表示は模式的な可視化であり、実測の三次元骨格回旋ではありません。

- 患者さんには医療上の診断ではないことを説明してください。

※ 本システムは写真に基づく姿勢評価の参考ツールであり、医療上の診断や骨格の実測を行うものではありません。

撮影・カメラについて›
きれいに分析する撮影のコツ

正面・右側面・左側面の3方向を、頭から足先まで全身が入るように撮影してください。

約2〜3m離れ、スマホは胸〜みぞおち付近の高さを目安にします。ガイド撮影では中央線と水平・垂直の目安を合わせてください。

撮影後はランドマークの位置を確認し、必要な場合は「ランドマークを微調整」から修正できます。

分析について›
分析結果の見方

3方向の写真とランドマークから、正面・側面・回旋のバランスを参考値として可視化します。

姿勢スコア、左右差、骨盤・脊柱バランス、脚軸、推定重心などを確認できます。

分析結果は姿勢評価の参考情報であり、医療上の診断を行うものではありません。

不要な履歴や顧客データは、各画面の削除機能から削除できます。
